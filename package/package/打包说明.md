# 终端安全检测工具 - PyInstaller 打包技术文档

## 一、打包技术选型

### 1.1 为什么选择 PyInstaller

| 工具 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **PyInstaller** | 成熟稳定、支持复杂依赖、社区活跃 | 体积较大 | 大型GUI应用 |
| py2exe | 轻量 | 维护滞后、PyQt6支持差 | 简单脚本 |
| cx_Freeze | 跨平台 | 配置复杂 | 跨平台需求 |
| Nuitka | 编译为C、体积小、性能好 | 编译慢、部分库兼容问题 | 性能敏感 |

**本项目选择 PyInstaller 的原因**:
- 需要打包 PyQt6 大型GUI框架
- 依赖外部可执行文件 (autorunsc64.exe, sigcheck64.exe)
- 需要数据文件嵌入
- 团队熟悉度高，问题易排查

### 1.2 打包模式对比

```
onefile (单文件)          onedir (文件夹)
    │                         │
    ▼                         ▼
┌─────────┐            ┌─────────────┐
│sectool  │            │ sectool/    │
│.exe     │            │ ├── sectool │
│(35MB)   │            │ │   .exe    │
│         │            │ ├── Qt6/    │
│ 自解压  │            │ ├── tools/  │
│ 到临时  │            │ └── ...     │
│ 目录运行 │            │ (分散)      │
└─────────┘            └─────────────┘
```

**本项目使用 onefile 模式**:
- 便于分发 (单个文件)
- 用户感知好 (双击即用)
- 启动稍慢 (解压过程)

## 二、核心技术原理

### 2.1 PyInstaller 工作流程

```
Python源码
    │
    ▼
┌─────────────┐
│ 分析阶段     │  ──► 解析import，构建依赖图
│ (Analysis)  │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 打包阶段     │  ──► 收集Python字节码、资源文件
│ (PYZ/PKG)   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│ 可执行文件   │  ──► 嵌入bootloader，生成exe
│ (EXE)       │
└─────────────┘
```

### 2.2 关键概念

#### Analysis (分析)
```python
# PyInstaller 自动分析
a = Analysis(
    ['main.py'],
    pathex=['app'],           # 额外的模块搜索路径
    binaries=[],              # 额外的二进制文件
    datas=[                   # 数据文件
        ('app/data/rules.json', 'data'),
        ('app/tools/*.exe', 'tools'),
    ],
    hiddenimports=[],         # 隐式导入 (关键!)
    excludes=[],              # 排除的模块
)
```

#### Hidden Imports (隐式导入)

**问题**: PyInstaller 通过静态分析找依赖，但有些导入是动态的

```python
# 这种动态导入 PyInstaller 检测不到
if some_condition:
    import PyQt6.sip  # 运行时才知道
```

**解决**: 显式声明
```powershell
--hidden-import PyQt6.sip
--hidden-import PyQt6.QtCore
```

#### Binary Collection (二进制收集)

**问题**: PyQt6 依赖大量 DLL，PyInstaller 可能漏收集

**解决**: 强制收集
```powershell
--collect-binaries PyQt6
```

## 三、遇到的问题与解决方案

### 3.1 错误一：No module named 'PyQt6.sip'

**错误信息**:
```
ModuleNotFoundError: No module named 'PyQt6.sip'
```

**原因分析**:
- `PyQt6.sip` 是 PyQt6 的内部绑定模块
- 通过 C 扩展动态加载，PyInstaller 静态分析检测不到

**解决方案**:
```powershell
--hidden-import PyQt6.sip
```

**技术细节**:
```python
# PyQt6/__init__.py 中的动态加载
import importlib
sip = importlib.import_module('PyQt6.sip')  # 运行时导入
```

---

### 3.2 错误二：DLL load failed while importing QtCore

**错误信息**:
```
ImportError: DLL load failed while importing QtCore: 找不到指定的程序
```

**原因分析**:
1. **Qt6 DLL 版本不匹配** - PyQt6 6.6.1 的 DLL 与系统 VC++ 运行时冲突
2. **缺少依赖的 VC++ Redistributable**
3. **DLL 路径问题** - 打包后找不到 Qt6 插件目录

**解决方案**:

#### 方案 A：降级 PyQt6 (采用)
```
# requirements-build.txt
PyQt6==6.4.2  # 从 6.6.1 降级
```

**原理**: 6.4.2 版本依赖更少的系统库，兼容性更好

#### 方案 B：显式包含 Qt6 DLL
```python
# sectool.spec 中手动添加
qt6_bin = Path(PyQt6.__file__).parent / 'Qt6' / 'bin'
dlls = [
    'Qt6Core.dll',
    'Qt6Gui.dll', 
    'Qt6Widgets.dll',
]
```

#### 方案 C：使用 --collect-binaries
```powershell
--collect-binaries PyQt6  # 收集所有 PyQt6 二进制文件
```

---

### 3.3 错误三：打包后运行时找不到数据文件

**错误信息**:
```
FileNotFoundError: [Errno 2] No such file or directory: 'tools/autorunsc64.exe'
```

**原因分析**:
- onefile 模式运行时，文件被解压到临时目录
- 代码中使用相对路径 `tools/autorunsc64.exe` 失效

**解决方案**:

#### 运行时路径适配
```python
import sys
from pathlib import Path

def get_resource_path(relative_path):
    """获取资源文件的正确路径"""
    if getattr(sys, 'frozen', False):
        # PyInstaller 打包后
        # sys._MEIPASS 是临时解压目录
        base_path = Path(sys._MEIPASS)
    else:
        # 源码运行
        base_path = Path(__file__).parent
    
    return base_path / relative_path

# 使用
autoruns_path = get_resource_path('tools/autorunsc64.exe')
```

#### 打包时嵌入数据
```powershell
--add-data "app/tools/autorunsc64.exe;tools"
# 格式: 源路径;目标目录
```

### 3.4 问题四：体积过大

**原始体积**: ~80MB

**优化策略**:

#### 1. 排除不需要的 Python 库
```powershell
--exclude-module matplotlib

--exclude-module pandas

--exclude-module PIL
--exclude-module unittest
--exclude-module tkinter

--exclude-module PyQt6.Qt3DAnimation
--exclude-module PyQt6.QtCharts
--exclude-module PyQt6.QtMultimedia
--exclude-module PyQt6.QtOpenGL
--exclude-module PyQt6.QtSql
# ... 共排除 30+ 个模块
```

#### 3. 使用 UPX 压缩 (可选)
```powershell
# 下载 upx.exe 放到 ./upx/ 目录
# PyInstaller 会自动检测并使用
```

**优化后体积**: ~35MB (减少 56%)

### 3.5 问题五：命令行窗口闪烁

**现象**: 执行 autorunsc64.exe 时弹出黑色命令行窗口

**原因**: Windows 默认创建子进程会显示控制台窗口

**解决方案**:
```python
import subprocess

# 隐藏窗口配置
startupinfo = subprocess.STARTUPINFO()
startupinfo.dwFlags |= subprocess.STARTF_USESHOWWINDOW
startupinfo.wShowWindow = subprocess.SW_HIDE

process = subprocess.Popen(
    cmd,
    stdout=subprocess.PIPE,
    stderr=subprocess.PIPE,
    startupinfo=startupinfo,           # 隐藏窗口
    creationflags=subprocess.CREATE_NO_WINDOW  # 不创建窗口
)
```

## 四、完整打包配置

### 4.1 构建脚本

**文件**: [build-minimal.ps1](file:///e:/Code/sectool_codex%20-%20副本/package/build-minimal.ps1)

```powershell
param(
    [ValidateSet('onefile','onedir')] 
    [string]$Mode = 'onefile'
)

# 1. 创建隔离的虚拟环境
$venv = Join-Path $here '.venv'
if (-not (Test-Path $venv)) {
    python -m venv $venv
}

# 2. 安装构建依赖
& $python -m pip install -r requirements-build.txt

# 3. 执行 PyInstaller
$args = @(
    '-m','PyInstaller',
    '--clean',                    # 清理缓存
    '--noconsole',                # 无控制台窗口
    '--name','sectool-minimal',
    '--paths', $appDir,           # 模块搜索路径
    '--hidden-import','PyQt6.sip', # 隐式导入
    '--collect-binaries','PyQt6', # 收集二进制
    '--add-data', "...",          # 嵌入数据
    '--exclude-module','...',     # 排除模块
    (Join-Path $appDir 'main.py')
)

& $python @args
```

## 五、运行时行为

### 5.1 onefile 模式运行机制

```
用户双击 sectool.exe
        │
        ▼
┌─────────────────┐
│ 1. 自解压到临时目录 │  ──► C:\Users\<user>\AppData\Local\Temp\_MEIxxxxxx\
│    (MEIPASS)    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. 加载 Python  │  ──► 从临时目录加载解释器和依赖
│    解释器       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 运行 main.py │  ──► 执行业务代码
│                 │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 4. 退出清理     │  ──► 删除临时目录 (除非崩溃)
└─────────────────┘
```

### 5.2 资源路径处理

```python
import sys
from pathlib import Path

def get_resource_path(relative_path):
    """
    获取资源文件路径
    同时支持源码运行和 PyInstaller 打包后运行
    """
    if getattr(sys, 'frozen', False):
        # PyInstaller 创建的临时目录
        base_path = Path(sys._MEIPASS)
    else:
        # 正常的源码目录
        base_path = Path(__file__).parent
    
    return base_path / relative_path

# 使用示例
tools_dir = get_resource_path('tools')
autoruns_path = get_resource_path('tools/autorunsc64.exe')
```
